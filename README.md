# Book Library

A simple JavaScript application built as part of **The Odin Project** curriculum.  
This project demonstrates how to use JavaScript objects, arrays, and DOM manipulation to create an interactive library where users can add and manage books.

## Features

- Add books to a personal library
- Display books dynamically on the page
- Store book information including:
  - Title
  - Author
  - Number of pages
  - Read / Not Read status
- Remove books from the library
- Toggle read status

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## Concepts Practiced

This project focuses on core JavaScript concepts such as:

- Object constructors
- Arrays of objects
- DOM manipulation
- Event handling
- Dynamic UI updates
- Separating structure, style, and behavior
